Your own private network

A self-hosted WireGuard mesh for your devices, compatible with NetBird.

Download Compare with NetBird

Three steps to a working network

One server, one client per machine, and rules for access.

  1. Run the server

    One stack: panel, sign-in, relay.

  2. Add your devices

    Install the client and sign in with a setup key.

  3. Set the rules

    Choose which groups can reach which machines.

What NetBirdy adds

Everything NetBird does, plus tools for self-hosters.

  • Control panel

    Dark or light theme, a command palette, offline help pages.

  • Web shield

    The reverse proxy slows or blocks scanners and AI crawlers.

  • Sign-in alarms

    Flags new device locations, failed login bursts and key misuse.

  • Offline reconnect

    Clients reconnect to peers after a restart while the server is down.

  • Signed updates

    Signed releases. The server caches client updates and can update itself.

  • Run it your way

    Podman stack, Pocket ID passkeys, Wazuh rules, no usage reports.

Try it on your machine

You need Podman and make.

Start the server

git clone https://github.com/Sudo-Ivan/netbirdy.git
cd netbirdy
make podman-build
make podman-up
# panel at http://localhost:8080

Your admin email and password are saved in podman/.env.

Connect a device

sudo netbirdy up \
  --management-url http://YOUR-SERVER:8081 \
  --setup-key YOUR-KEY
netbirdy status

Create the key under Setup Keys. Get clients from releases.
