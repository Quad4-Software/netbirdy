Download NetBirdy

Clients for Linux, Windows and macOS, and images for the server.

Files are listed on the GitHub releases page.

Linux

deb, rpm and tar.gz

  • Open the releases page to pick a package for your architecture.
sudo apt install ./netbirdy_*_linux_amd64.deb
# or
sudo dnf install ./netbirdy_*_linux_amd64.rpm

The package replaces the NetBird package and keeps /etc/netbird.

Windows

Installer for 64-bit Windows

  • Open the releases page to get the installer.

Run the installer as an administrator. It installs the netbirdy command and starts the service.

macOS

Apple silicon and Intel

  • Open the releases page to get the package for your Mac.
sudo installer -pkg netbirdy_*_darwin_arm64.pkg -target /

Desktop app

Tray app and window

    Server

    Container images on GHCR

    podman pull ghcr.io/sudo-ivan/netbirdy-server
podman pull ghcr.io/sudo-ivan/netbirdy-dashboard

    For a complete local setup, follow the quick start.

    Verify

    Signatures and checksums

    sha256sum -c netbirdy_*_checksums.txt --ignore-missing
gh attestation verify FILE --repo Sudo-Ivan/netbirdy

    Each file has a .sig signature. The updating guide explains how to check them.
