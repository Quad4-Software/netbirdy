# Support

NetBirdy is an independent fork of NetBird maintained at
https://github.com/Sudo-Ivan/netbirdy. NetBird GmbH and the upstream NetBird
project do not support NetBirdy.

- Bugs and questions: https://github.com/Sudo-Ivan/netbirdy/issues
- Security reports: do not open a public issue. Use a private GitHub security
  advisory at https://github.com/Sudo-Ivan/netbirdy/security/advisories/new.

Only the latest NetBirdy release is supported.
