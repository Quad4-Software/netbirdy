NetBirdy is a community fork of NetBird focused on self-hosted use:
a single combined server binary, an embedded identity provider, a
re-themed dashboard and an offline-capable client.

## Compatibility

- The wire protocol, Go module paths, environment variables, persistent
  paths and API surface follow upstream NetBird.
- Existing NetBird clients and servers interoperate with the fork.
- User-facing names, icons and packages are rebranded to NetBirdy.
