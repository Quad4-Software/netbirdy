# Security policy

## Reporting

Report vulnerabilities through GitHub private vulnerability reporting:
https://github.com/Quad4-Software/netbirdy/security/advisories/new

Do not open a public issue for a suspected vulnerability.

## Supported versions

Only the latest release is supported. Update before reporting a problem in an
older version.

## Scope

In scope: the management server, client, signal and relay services, reverse
proxy and shield, anomaly detection, dashboard, and Podman preview stack.

Out of scope: third-party services you deploy separately, social engineering,
and denial of service against infrastructure you do not control.

## Expectations

Reports are acknowledged when time permits. This is a personal project, so fix
times are not guaranteed. Credit is given in release notes unless you opt out.
