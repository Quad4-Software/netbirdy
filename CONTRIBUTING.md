# Contributing

Open issues and pull requests at https://github.com/Sudo-Ivan/netbirdy.

See docs/maintaining.md for the upstream sync flow, the rebrand rules, and the
release process.

Contributions are licensed under the license of the directory you touch
(see LICENSES/REUSE.toml). The fork does not require the upstream NetBird CLA;
upstream CLA text inside dashboard/ is kept for upstream provenance only.
